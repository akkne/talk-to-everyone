# Фронтенд

Текущий код использует API v1. Целевой [контракт v2](../backend/docs/backend.md), расхождения и [план интеграции](../docs/integration.md). `PLAN.md` — архивный план v1.

Текущий [роадмап по overall](../docs/roadmap.md). Первый этап реализован: в локальном осмотре работают WASD, обзор, коллизии, два яруса с рампами и посадка по E. Нажмите на сцену для управления; если захват мыши недоступен, используйте стрелки. Проверки: `npm test`, сборка: `npm run build`. Полный переход состояния игры на v2 и проверка с сервером ещё впереди; старая отправка `SendCamera` удалена.

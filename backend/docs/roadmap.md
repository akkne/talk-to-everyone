# Роадмап бэкенда

Один ASP.NET Core-проект с папками по назначению. `[x]` — реализовано, `[~]` — частично.

1. [x] Основа: .NET 10, SignalR, PostgreSQL/EF Core, миграция, env, health endpoints.
2. [x] Хранение: сессия, игроки, 10 NPC, сообщения, доска, выборы; уникальные ограничения.
3. [x] Вход: персональные токены, ведущий, повторный вход, полный снимок; одна игра.
4. [x] NPC: три случайные пары и четыре актёра, общая история друзей, публичные детали без секретов.
5. [x] Вопросы: проверка фазы, лимита и текста, история, тестовый ответ без LLM.
6. [~] Облачная LLM: OpenAI-compatible endpoint, контекст NPC, таймаут, JSON-ответ. Нужна проверка с реальным провайдером.
7. [x] Раунды, три окна выбора, личная доска, финальное раскрытие и счёт.
8. [~] Кресла и позы: занятость, посадка, вставание, базовая скорость и рампы. Нужны точные коллизии мебели.
9. [~] Ручной сценарий на двух клиентах, конфликт кресла, допрос, три выбора, финал и восстановление после рестарта прошли. Остались reconnect во время игры и реальная LLM.
10. [~] Идемпотентность команд доски, вопросов и кресел по `requestId`; базовый лимит `SendPose`. Нужна проверка при reconnect и сбоях.

Фронт переведён на v2; текущая схема описана в [интеграции](../../docs/integration.md). Следующий этап: закрыть пункты 8–10.

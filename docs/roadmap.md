# Текущий статус и дальнейшая работа

Фронтенд использует SignalR API v2 и серверный `SceneSpec`. Локальный preview-клиент удалён. Игровой API (`backend/Backend.csproj`) хранит состояние в PostgreSQL, ведёт раунды, вопросы, доску и результаты. Передвижение, коллизии и посадка используют серверное подтверждение; клиент предсказывает движение по геометрии сцены.

Отдельный проект `backend/TalkToEveryone.Api/` содержит прототип Ollama с очередью генерации и моделями диалога. Текущий `docker-compose.yml` собирает этот прототип; объединение его с игровым API остаётся отдельной задачей.

## Осталось проверить и реализовать

- Сквозной сценарий в двух браузерах с PostgreSQL: вход, четыре раунда, три окна выбора, вопросы, финал, переподключение и рестарт сервера.
- Согласовать геометрию коллизий мебели между клиентом и сервером. Сервер пока проверяет границы, скорость и высоту, но не все предметы сцены.
- Подключить генерацию Ollama к игровому API либо настроить совместимый LLM endpoint и проверить ответы реальной модели.
- Уточнить развёртывание: выбрать единый бэкенд для Docker Compose и описать его переменные окружения.

Контракт — в [документации API](../backend/docs/backend.md), текущий запуск — в [README бэкенда](../backend/README.md).
